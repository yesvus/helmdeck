# Naming

Goal: short, brandable, MIT-friendly. Ships as `@yesvus/<name>`.
Checked 2026-09-23 via `registry.npmjs.org`. 404 means free unscoped,
200 means taken unscoped but still usable as `@yesvus/*`.
